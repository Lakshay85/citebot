# BRD: Citebot
**Business problem:** support teams spend most hours on questions already answered in docs; chatbots that invent policy create refunds, churn and legal risk.
**Value:** deflect doc-answerable tickets; route the rest faster with context already attached.
**Cost model:** about $0.00016 per answer at list price; a 10,000 answers/month workload is about $1.60 in model cost.
**Risks:** wrong answers (mitigated by 3 gates and eval gating), free-tier rate limits (mitigation: paid tier or self-hosted model), prompt injection from uploaded docs (see SECURITY.md).
**Scope for this portfolio piece:** working demo, measured quality, documented security. Not a production SLA.
